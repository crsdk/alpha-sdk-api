Alpha Camera REST API

An HTTP server that runs on your machine and controls a connected Sony Alpha camera.

API reference & request console →

All operations, with a console that sends real requests to the server on your own machine.

Source, releases and setup →

Building the server, installing it, and the Sony SDK it needs.

Quick check

With the server running, this should return the connected cameras:

curl http://localhost:8080/api/cameras
The request console runs entirely in your browser and talks directly to http://localhost:8080. This site never receives your requests, and no camera is reachable from the public internet because of it.
