:::

## Two kinds of MCP server

MCP (Model Context Protocol) lets AI assistants like Claude and Cursor connect to outside tools. This project ships **two different kinds**, and they do very different jobs:

| | **Docs MCP** | **Camera Control MCP** |
|---|---|---|
| **What it does** | Answers questions about the SDK, camera models, and REST API from indexed documentation | Operates a connected Sony Alpha — read settings, change ISO/shutter, shoot, review the frame |
| **Where it runs** | Hosted (cloud), read-only | Local — you build it from this repo |
| **You need** | Just an MCP-capable AI client | The built server + a camera on USB |
| **Guide** | [Docs MCP → Setup](/alpha-sdk-api/mcp-server/setup/) | [Camera Control](/alpha-sdk-api/mcp-server/camera-control/) |

Pick the one that fits what you're doing: **Docs MCP** to research the SDK, camera models, and REST API while you build; **Camera Control MCP** to actually operate a camera. They're independent — you can use either, both, or neither.
